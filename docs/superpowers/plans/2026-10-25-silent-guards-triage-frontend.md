## Contract changes and evidence

- Cell detail: `commonKnowledgeSize` is a required decimal shannon string; negative, malformed, over-capacity, and byte-breakdown mismatch states produce a contextual error. Regression test was red before the fix.
- `/charts/hash-rate` and `/charts/difficulty`: decimal integer `value` is formatted through BigInt in homepage and full-chart readouts. Only SVG coordinates use Number. `/statistics/network.hashRate` is nullable when no time span exists and displays an em dash.
- Capacity bars use the real ratio; zero has zero width. `CommandPalette` overlay now portals to `document.body`: a header with `backdrop-filter` creates a fixed-position containing block, and the structural test verifies the overlay is outside it. Browser pixel QA was unavailable because no browser connector was available.
- The knowledge-size net-flow chart now uses the existing exact daily-delta calculation on decimal CKB strings; a missing/malformed day fails rather than becoming zero. Regression test was red before the fix. `formatCkbValue` accepts strings only, so callers cannot silently feed pre-rounded JavaScript numbers.
- Deleted the unmounted `useRealtimeTransactions` hook after import search found no consumers.
- DAO statistics reports `averageDepositDays: null` when no eligible deposit exists; the card displays an em dash. Spore/cluster optional owner lock hashes and synthetic-cluster creation block display absence rather than fabricated values.
